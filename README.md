# CareerOneStop redesign: P4 prototype

Student prototype for CS 4501 Usability Engineering (Fall 2026). Not affiliated with CareerOneStop. All scholarships and jobs shown are simulated sample data.

- `process/design-log.md`: record of how the AI agent was used, including every prompt, proposal and decision.
- `process/sketches/`: the team's hand-made design artifacts the prototype is built from.
